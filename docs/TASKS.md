### [x] T1.1 - uninstall.ps1 default behavior (remove kit commands/agents, restore settings.json)   (Story S1)
- **Goal:** `uninstall.ps1` with no switches removes exactly the kit's own installed files and restores the
  prior `settings.json`, reversing what `install.ps1` put down, without touching anything else.
- **Touches:** `uninstall.ps1`
- **Do:** Implement `param([switch]$Full)`. Reuse install.ps1's `Have` helper pattern. Remove ONLY the 6
  kit command files (`scaffold.md, design.md, taskmap.md, proto.md, spec.md, build.md` - and the wider set
  install.ps1 actually ships: `assets, tidy, stories, diagram, audit, grade` per DESIGN R6/R7) from
  `%USERPROFILE%\.claude\commands\` and the kit's agent files from
  `%USERPROFILE%\.claude\agents\` by exact name, matching install.ps1's file lists (do not delete the
  folders or any other file in them). Restore `%USERPROFILE%\.claude\settings.json` from
  `settings.json.bak` if that backup exists; otherwise warn and leave `settings.json` untouched. Print a
  dry-run list of what would be removed before removing it.
- **Acceptance:** After running `uninstall.ps1` (no switches), the kit's command + agent files named above
  are gone from `~/.claude/commands` and `~/.claude/agents`, and `settings.json` matches the restored
  `.bak` (AC1 from Story S1).
- **Depends on:** none
- **Context:** install.ps1 copies `global\commands\*.md` -> `%USERPROFILE%\.claude\commands\` and
  `global\agents\*.md` -> `%USERPROFILE%\.claude\agents\`, and writes `%USERPROFILE%\.claude\settings.json`
  after backing up any prior copy to `settings.json.bak`. Keep the command/agent name lists here in sync
  with install.ps1's lists - that sync is the whole point of this task.

### [x] T1.3 - uninstall.cmd launcher   (Story S1)
- **Goal:** A double-clickable launcher for `uninstall.ps1`, mirroring `install.cmd`'s shape.
- **Touches:** `uninstall.cmd`
- **Do:** Create `uninstall.cmd` containing
  `powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0uninstall.ps1" %*` followed by `pause`, ASCII
  only, exactly mirroring how `install.cmd` launches `install.ps1`.
- **Acceptance:** Running `uninstall.cmd` (with or without `-Full` passed through `%*`) invokes
  `uninstall.ps1` with the same arguments and pauses for the user to read the output.
- **Depends on:** T1.1
- **Context:** `install.cmd` is the pattern to mirror - same `powershell -NoProfile -ExecutionPolicy Bypass
  -File "%~dp0<script>.ps1" %*` + `pause` shape, per CLAUDE.md's "Global commands/agents" convention of
  keeping installer/uninstaller symmetric.
