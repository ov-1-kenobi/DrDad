# Drop your references here

Put datasheets, app notes, pinout sheets, and design references in this folder
(`.pdf`, `.txt`, `.md`). Subfolders are fine; `web/` is created automatically for
pages captured via `ingest_url`.

Then either run the `index_datasheets` tool from Claude Code, or just call
`search_datasheets` - it auto-indexes on first use. Re-run `index_datasheets`
after adding or changing files.

Scanned/image-only PDFs have no extractable text - OCR them first.
